STILLWATER CLEANING LLC WEBSITE

Files
- index.html: complete responsive website
- assets/stillwater-logo.png: transparent logo supplied for the website

Preview
Open index.html in a modern web browser. The website works without a build step, framework, external fonts, or external scripts.

Publish
Upload index.html and the assets folder together to your web host, keeping the same folder structure. If you change the logo filename, update the image src in index.html.

Quote form
The quote form prepares an email addressed to tsmothers25@icloud.com using the visitor's default email app. It does not send or store form submissions on a server. To collect quotes directly on the website, connect a form backend before publishing.
